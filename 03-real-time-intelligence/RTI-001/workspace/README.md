# RTI-001 Fabric workspace

This directory is managed through Microsoft Fabric Git integration for the temporary `Northstar Data Platform - RTI-001` branch workspace.

Fabric-generated Eventstream, Eventhouse, KQL Database, KQL Queryset, Real-Time Dashboard, Activator, and supporting item definitions belong here. Architecture documents, portable event contracts, tests, and evidence remain in the parent RTI-001 directories.

Do not store event data, environment identifiers, connection values, credentials, notification recipients, or secrets in this directory.
