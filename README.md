# Microsoft Data + AI Mastery

Bryan Cetani's evidence-based development system for progressing from strong Microsoft certifications to demonstrated mastery in enterprise data and AI architecture.

## North star

Build and document production-grade systems that prove the ability to architect, engineer, govern, operate, and explain Microsoft Fabric and AI solutions at enterprise scale.

## How this repository works

- `ROADMAP.md` defines the sequence and outcomes.
- `SKILLS.md` is the competency scorecard.
- `PROGRESS.md` is the monthly evidence log.
- GitHub Issues hold epics and testable work items.
- GitHub Milestones group work into delivery horizons.
- GitHub Projects is the command center for priority and status.
- The numbered folders hold architecture decisions, code, tests, demos, runbooks, and retrospectives.

Completion means more than producing code. A work item is complete only when its acceptance criteria, tests, documentation, and evidence links are all present.

## Weekly operating rhythm

1. Select one measurable outcome for the week.
2. Move no more than two issues into `In Progress`.
3. Build, test, and document evidence in the relevant track folder.
4. Add evidence links and a short retrospective to the issue.
5. Update `PROGRESS.md` and reassess any affected skills monthly.

## Evidence standard

Strong evidence includes runnable code, automated tests, architecture diagrams, decision records, operational telemetry, cost or capacity analysis, security controls, demos, and concise explanations of tradeoffs.
